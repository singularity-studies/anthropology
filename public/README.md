# Public Derivative Outputs

No participant-derived artifact has been authorized or published.

Every future artifact in this directory requires sidecar metadata named `<artifact>.metadata.json`. Participant-derived artifacts additionally require a matching versioned record under `governance/public-releases/` with passed disclosure and de-identification reviews and a verified content hash.

Public release does not make re-identification risk impossible. Withdrawal, correction, or privacy remediation may require removal and history rewriting.
