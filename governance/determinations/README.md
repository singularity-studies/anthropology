# Public Determination Records

No determination has been recorded.

This directory is reserved for repository-local, non-sensitive governance summaries that validate against `schemas/governance-determination.schema.json`. Each record states only the determination type, explicit outcome, rationale, safe basis summary, responsible role, and time needed for internal readiness documentation.

Do not store ethics letters, legal advice, consent materials, contracts, signatures, reviewer identities, participant information, confidential institutional records, or other sensitive source documents here. A safe external reference may identify where an authoritative source is controlled without reproducing it.

A readiness slot binds one determination record by repository-relative path and SHA-256. Repository validation confirms this public summary's structure and bytes; it cannot grant, replace, or substantively validate any external ethics, legal, institutional, community, professional, or contractual determination.
